# Introduction to calibration and fitting of infectious disease models

R practicals for the "Introduction to model fitting and calibration" part of
the [MPPR modular short course](https://vclass.g-wac.org/local/gwac_landing/index.php?track=mppr&page=overview).
Both fit an SIR model to the 1978 boarding-school influenza outbreak in
`practicals/data/`.

* `practicals/01_least_squares_mle_practicals.qmd`: Practical 1, least squares and maximum likelihood estimation
* `practicals/02_mcmc_practicals.qmd`: Practical 2, Bayesian inference and Markov chain Monte Carlo

Render either with `quarto render practicals/<name>.qmd`. The slides are in
[mppr_intro_to_model_fitting](https://github.com/GWAC-MPPR/mppr_intro_to_model_fitting).
